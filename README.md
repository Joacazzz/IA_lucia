# Lucía – Assistente de Tarefas em Python

Lucía é um assistente simples de terminal desenvolvido em Python para gerenciamento de tarefas.
O sistema permite registrar, listar, concluir e remover tarefas utilizando comandos em linguagem natural.

O objetivo do projeto é praticar conceitos de:

* Python
* Manipulação de arquivos
* Estruturas de dados
* Processamento de linguagem natural
* Organização de código

---

## Funcionalidades

* Adicionar novas tarefas
* Listar tarefas registradas
* Marcar tarefas como concluídas
* Remover tarefas
* Armazenamento em arquivo JSON
* Interpretação básica de comandos usando NLP

---

## Tecnologias utilizadas

* Python
* spaCy (Processamento de linguagem natural)
* JSON (armazenamento de dados)

---

## Estrutura do Projeto

```
lucia/
│
├── lucia.py
├── tarefas.json
└── README.md
```

* **lucia.py** → código principal do sistema
* **tarefas.json** → arquivo onde as tarefas são armazenadas
* **README.md** → documentação do projeto
